# Fashion Color Recommender

End-to-end color analysis and clothing-recommendation app:

1. **Skin analysis** — MediaPipe FaceMesh locates your face, samples cheek
   pixels, and converts them to CIELAB. The **Individual Typology Angle
   (ITA)** classifies your **Skin Tone** (Very Fair → Very Dark); the Lab
   hue ratio classifies your **Undertone** (Warm / Cool / Neutral).
2. **Palette lookup** — `fashion_and_color_recommendation.csv` maps
   Skin Tone × Undertone (× optional body shape) to recommended/avoid
   color families and styling tips (fit, materials, patterns, jewelry,
   shoes).
3. **Garment indexing** — the "Colorful Fashion" object-detection dataset
   (PASCAL-VOC annotations over real outfit photos) is parsed once offline:
   every garment bounding box (shirt, pants, jacket, dress, skirt, shorts)
   is cropped and its dominant color found via KMeans, then converted to
   CIELAB.
4. **Matching** — `CIEDE2000` (the perceptual Delta-E 2000 formula, hand
   implemented and unit-tested against Sharma et al.'s reference values)
   ranks every indexed garment by color distance to your recommended
   palette, penalizing garments that are close to your "avoid" colors.
5. **UI** — a Streamlit app lets you snap a webcam selfie (or upload a
   photo) and shows your palette + the best-matching real clothing photos.
6. **My Closet** — upload photos of your *own* clothes. Each item gets a
   Personal Match % against your palette, any two items get an Outfit
   Harmony % (does this shirt work with these jeans?), and every valid
   outfit combination across your uploads is auto-generated and ranked.
   You can also save an item into a persistent catalog so it shows up in
   future "Matching clothing items" results too.
7. **Personal Color PDF Report** — download a comprehensive, beautifully
   formatted PDF summary containing your skin tone, undertone, ITA metrics,
   recommended & avoid swatches with HEX codes, and fashion styling tips.
8. **Shopee Smart Shopping Links** — toggleable shopping assistant that generates
   direct search links on Shopee Indonesia for any recommended color swatch or matching
   clothing piece, customized with target category filters (Semua, Wanita, Pria).

## The "My Closet" feature in detail

Switch to **👕 My Closet** in the sidebar. It answers three related but
distinct questions:

1. **"Does this ONE item suit me?"** — Each upload's dominant color
   (KMeans, same as the offline indexer) is compared via CIEDE2000
   against your recommended *and* avoid palettes, producing a 0–100%
   **Personal Match** score and a verdict (*Great match* / *Good match* /
   *Wear with caution* / *Better to avoid*). Items that land close to an
   "avoid" color are flagged and penalized.

2. **"Do THESE items work together?"** — For any two items (e.g. a shirt
   + jeans), `closet_engine.harmony_score` computes each garment's hue
   angle and chroma in Lab space and scores the pairing using classic
   color-theory relationships:
   - **Neutral** (gray/beige/navy/black/white) pairs with almost
     anything → high score.
   - **Monochrome / analogous** hues (close together on the color wheel)
     → high score.
   - **Complementary** hues (~180° apart) → good, bold pairing.
   - The **"muddy middle"** (~50–100° apart, especially if both are
     highly saturated) → lowest score — this is the classic "these two
     colors are fighting each other" zone.

   A dedicated "Check a specific pairing" widget lets you pick any two
   uploaded items and see this instantly as a percentage (this is the
   literal "shirt + jeans = X% recommended" feature).

3. **"What's my best outfit from everything I uploaded?"** — Tag each
   item's category (top/bottom/dress/outer) and `generate_combos` builds
   every valid slot combination (top+bottom, top+bottom+jacket, dress
   alone, dress+jacket), scores each as
   `overall = 0.5 * avg(personal match) + 0.5 * avg(pairwise harmony)`,
   and ranks them so you get a leaderboard of your best pairings.

4. **Add to the dataset** — an "➕ Add to garment catalog" button on any
   analyzed item saves its crop + dominant color into
   `data/processed/user_garments.csv` / `data/processed/user_crops/`
   (kept separate from the original Colorful Fashion catalog so it's easy
   to reset). `Recommender` merges this in automatically, so your own
   clothes will start appearing in future "Matching clothing items"
   results in the "Get My Colors" tab too.

Both the harmony rules and the personal-match distance→percentage
mapping are heuristics, exactly like the skin-tone/undertone estimation —
useful as a quick, consistent guide, not a hard rule.

## Setup

```bash
cd fashion-color-recommender
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

> **mediapipe version note:** `mediapipe.solutions.face_mesh` (the classic
> FaceMesh API this project uses) was removed from mediapipe wheels newer
> than the 0.10.1x line. `requirements.txt` pins `mediapipe==0.10.14` for
> this reason — don't upgrade it without switching `skin_analyzer.py` to
> the new Tasks API.

## 1. Build the garment catalog (run once)

The garment catalog is derived data and isn't committed pre-built at large
scale in this repo layout — generate it from the raw dataset:

```bash
python -m src.garment_indexer
```

This walks all `data/raw/colorful_fashion/Annotations/*.xml`, crops every
`shirt/pants/jacket/dress/skirt/shorts` bounding box from the matching
`JPEGImages/*.jpg`, saves a thumbnail to `data/processed/crops/`, computes
each garment's dominant CIELAB color via KMeans, and writes
`data/processed/garment_catalog.csv`. On the full dataset (2,682 photos,
~5,500 garments) this takes well under a minute on CPU.

Useful flags:

```bash
python -m src.garment_indexer --limit 100        # quick smoke test
python -m src.garment_indexer --classes shirt,dress   # only index some classes
python -m src.garment_indexer --no-crops         # skip saving thumbnails
```

## 2. Run the app

```bash
streamlit run app.py
```

Streamlit will open in your browser. Choose **Webcam** in the sidebar and
click "Take a selfie" — `st.camera_input` uses your browser's camera
permission prompt directly, so **the app can use your own webcam as its
vision input with no extra driver setup**. You can also switch to
**Upload a photo** to analyze an existing image instead.

For best results: face the camera directly, use even/natural lighting,
and avoid heavy makeup or colored lighting that could skew the sampled
skin color.

## Camera robustness: automatic white balance (AWB)

Skin-tone/undertone measurement from a photo is sensitive to the
camera's white balance -- a cheap webcam or a tinted indoor light can
shift the measured color enough to flip "Warm" into "Cool." Before
sampling cheek pixels, `skin_analyzer.py` runs a from-scratch AWB
correction (`white_balance.py`):

- **Face-excluded gray world** -- the color cast is estimated from the
  background *around* your face, not from your face itself. This is a
  deliberate design choice: correcting a whole selfie with plain
  gray-world (as most quick AWB demos do) would try to neutralize the
  *skin's own real undertone* right along with the camera's cast, since
  a selfie frame is mostly skin. Estimating from the background avoids
  that.
- If the background doesn't look neutral (e.g. a strongly colored wall
  or a colorful outfit filling most of the frame), the correction is
  automatically damped -- gray-world assumes the background averages
  toward gray, and a highly saturated background breaks that
  assumption. There's also a whole-image "Shades of Gray" fallback for
  when there's too little background to sample at all (e.g. a very
  tight face crop).
- The correction is gain-clamped and applied at partial strength, so it
  meaningfully reduces (rather than silently overcorrecting) a camera's
  cast.

This is a best-effort heuristic, not a perfect fix -- a severe color
cast still won't be fully undone. It's toggleable in the sidebar
("Camera correction") so you can compare the corrected vs. raw reading,
and the method + gains used are shown under your results.

## How the color science works

- **CIELAB conversion**: standard sRGB → linear RGB → XYZ (D65 white
  point) → Lab, implemented from scratch in `skin_analyzer.py` (no
  extra color-science dependency required).
- **ITA**: `ITA = atan2(L* - 50, b*) * 180 / π` (Del Bino & Bernerd bands:
  Very Fair > 55°, Fair 41–55°, Medium 28–41°, Olive 19–28°, Brown
  10–19°, Very Dark < 10°).
- **Undertone**: heuristic ratio of Lab `b*` (yellow axis) to `a*` (red
  axis) — strongly yellow-skewed is Warm, strongly red-skewed (low b*/a*
  ratio) is Cool, in between is Neutral.
- **CIEDE2000**: full implementation of Sharma, Wu & Dalal (2005) in
  `recommender.py`, verified against their published reference test
  values (e.g. `ciede2000((50,2.5,0), (73,25,-18)) == 27.1492`).
